# {frontmatter.title}

A blog of static routes deploys anywhere that can serve files. Ruvyxa ships adapters for Node, Bun,
Deno, Vercel, Netlify, Cloudflare, Railway, Render, Firebase, AWS, and plain static hosting.

## Build for a target

Install the adapter and name it:

```bash
npm install --save-dev @ruvyxa/adapter-static
npm run build -- --adapter static
```

The adapter shapes the output for its platform. If a route needs something the target cannot do, the
build says so and stops, rather than deploying something that fails at request time.

## Set the site URL first

`ruvyxa.config.ts` starts with `site.url` pointing at `http://localhost:3000`. Change it, or set
`RUVYXA_SITE_URL` in the deployment environment — every absolute URL the build publishes is derived
from it:

- `sitemap.xml` and `robots.txt`, from the route manifest
- `rss.xml`, from the frontmatter of every post
- `content.json` and `search-index.json`, for a client-side search box
- `llms.txt`, an index for agents that read the site

Those last four come from `content: true`. They are generated from the posts themselves, so nothing
has to be listed a second time.

## Before you ship

```bash
npm run check
npm run build
```

`check` type-checks, compares the development and production route tables, and smoke-renders. It is
faster than finding the same problem in a deployment log.
